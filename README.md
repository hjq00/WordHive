# WordHive

**把单词酿成记忆。** 一款可以像刷抖音一样刷着背单词的软件——一屏一词，上滑就走，停留多久就自动判定认识还是不认识，不用点按钮。面向考研英语一 / 考研二 / 六级。

- 停留即判定：在一个词上停留多久，就记为认识 / 模糊 / 不认识
- 间隔复习：按遗忘曲线安排回访
- 语境素材：真题阅读 / 听力 / 长难句，按考试分类
- 词条详解：联想、词根词缀、派生、正反义、短语，左右滑动查看

技术栈：原生 ES Module + CSS（零运行时依赖），Capacitor 7 打包 Android。

## 快速开始

```bash
npm install
# 先按下节准备词库数据，否则 src/data/books.js 的 import 会失败
npx cap sync android
cd android && ./gradlew assembleDebug
```

## 准备词库（必须）

本仓库**不包含词库数据**——词库由纸质资料扫描重建，版权状态待确认。clone 后需自行准备 5 个文件，导出名与结构见 [`src/data/words/README.md`](src/data/words/README.md)：

- `src/data/words/kaoyan-5500.js` → `KAOYAN_5500`
- `src/data/words/hongbao.js` → `HONGBAO_OCR`
- `src/data/words/cet6-days.js` → `CET6_DAYS`
- `src/data/words/zhenti-words.js` → `ZHENTI_WORDS`
- `src/data/enrichment.js` → `ENRICHMENT`

准备好后同步到 `www/src/data/`，再执行 `npx cap sync android`。

## 视频课

视频未随源码分发，默认从一个公开的 Cloudflare R2 地址在线播放。换成自己的存储：App「我的 → 视频课地址」填直链前缀（末尾不带斜杠）。上传脚本：`scripts/r2-upload.mjs`。

# 开发日志（以下内容按版本记录迭代过程）

<h1 align="center">轻词 · 考研 / 六级背单词</h1>

<p align="center">一屏一词，滑动切换；不点按钮，按停留时长自动判定掌握程度；按记忆曲线安排复习。</p>

## 一、这是什么

面向考研英语（一/二）与六级备考的**移动端背词应用原型**。设计目标是"轻"：打开即背，一次只处理一个词，不登录、不社交、不做学习以外的打扰。

- 纯静态前端：零构建、零依赖、零后端，`localStorage` 持久化，可离线运行。
- 真机尺寸设计：430px 内容宽，安全区适配，所有可点区域 ≥ 44px。
- 五屏结构：学习 / 复习 / 素材 / AI / 我的。

## 二、核心交互：不设三档按钮，看停留时长

这是与常见背词 App 最大的不同。卡片底部没有"不认识 / 模糊 / 认识"，只有一根判定环。

**整页没有卡片容器**：单词以衬线大字直接排在背景上，背后还有一层同词巨型水印；释义、联想、例句、真题入口全部直接落在纸色背景上，只用细线与留白分层。这样视线先落在词上，再落到解释上，页面也不会被卡片切成一格一格。

**判定规则**（可在「我的 → 停留判定」切换宽松 / 标准 / 严格）：

| 行为 | 判定 | 下次复习 |
| --- | --- | --- |
| 停留 < 2s（快速划过） | 认识 | 首次 1 天，之后 ×ease |
| 停留 2s – 5s | 模糊 | 约半天 |
| 停留 > 5s | 不认识 | 10 分钟后 |
| 点收藏 / 展开详解 | 不认识 | 10 分钟后 |
| 连点两次发音 | 最多判为模糊 | — |
| 停留 > 40s（可能走神） | 模糊 | 约半天 |

- 右上角的环形进度实时显示已停留秒数，跨过阈值会变色（绿 → 琥珀 → 红），判定过程是**可见**的。
- 判错可以改：点判定环，弹出三档修正，修正后仍按记忆曲线排期。
- 进入下一张卡时才结算，避免"读例句读到一半就被判不会"。
- 页面切后台会暂停计时；单次停留上限 60s，避免放着手机被判"不认识"。

> 设计取舍：停留时长是"回忆是否顺畅"的间接信号，不完美。因此保留了手动修正、收藏/详解这类显式信号，并在首次进入时用一行文案说明规则，避免算法变成黑箱。

## 三、记忆机制

- **弹性计划（默认开启）**：不设每日配额，顶部只显示“今日 N”，不出现“N/20 今日”的欠债感；一组刷完可以停，也可以再来一组。
- 三档反馈 + SM-2 变体：`ease` 1.3–2.8，间隔上限 180 天。
- 四状态：未学 → 学习中（间隔 < 1 天）→ 复习中 → 已掌握（间隔 ≥ 21 天且 ≥ 3 次正确）。
- 复习队列按逾期时长排序，分「已逾期 / 今天到期」两组。
- 用 `R = e^(−t/S)` 估算记忆保持率，展示在复习页与单词详情里。
- 提醒：每日固定时间 + 到期数 > 0。**纯前端无法做锁屏推送**，因此实现为「打开应用时的应用内提醒条 + 系统通知（需授权）」；设置里提供「开启通知」按钮，并如实说明限制。

## 四、单词详情

卡片只放决策必需的信息（词、音标、发音、释义、联想、一条例句、真题角标）。完整信息在底部抽屉，按认知顺序分八组：

1. 释义 + 注释（辨析、搭配、易混点）
2. 例句（目标词高亮）
3. **联想记忆**（拆分 / 谐音 / 词根 / 字母 / 场景，可"换一个"）
4. 真题例句（带年份题号）或影视台词（带剧集出处）
5. 词根词缀（可读的词块 + 记忆钩子）
6. 派生词
7. 近义词 / 反义词
8. 常用搭配

联想记忆的写法参考了备考圈常用的四类方法：词根词缀拆解、谐音联想、拆分组合、故事/场景串联（研招网与主流备考资料的通用做法）。联想只作为脚手架，详情页会提示"再靠例句把词义固定住"。

## 五、内容

- **词书：四本，共 7786 词**（跨书重复的词各自独立记进度）
  - **红宝书 · 考研必考词** 3451：精缩版 250 页 OCR（200 DPI），音标与词形由 ECDICT 补齐。
  - **考研 5500 · 你还在背单词吗** 1768：332 页 OCR。OCR 释义会混入助记与例句，故释义统一用 ECDICT 校订，只取书里的词头。
  - **红宝书 · 十年真题词汇** 1308：该 PDF 有文字层，直接抽词头（1495 → 1311），释义用 ECDICT。
  - **六级核心词 · 1–7 天** 1259：资料库 7 份有文字层的 PDF，每天 180 词。
  - **每本书独立记忆**：卡片键为「书 id + 序号」，同一个词在不同书里各有一条记忆曲线，互不影响。
- **词条补全**：`design/build-enrichment.py` 生成 `src/data/enrichment.js`（约 3MB），四本书共用，覆盖 4800 个不同词，**每个词的学习卡片都有例句**。
  - 释义 4800、注释 4785、发音（音标）4792、联想记忆 4395、派生/词形 3819、近义词 4782、反义词 1933、词根词缀 2324、例句 4800、真题语境 326。
  - 例句来源按词条计：WordNet 真实例句 6101、明确标注“拼装练习句”1637、精读材料 48。WordNet 例句必须是包含目标词本身的句子，否则改用练习句。
  - 其他来源：ECDICT（释义、音标、词形、考纲标签、COCA 词频）、你提供的《真题词汇注释》（真题语境与部分同反义）、8 篇精读材料。联想按词根词块或英释生成，不编造词源。
- **素材**：
  - 真题阅读 8 篇（原文 + 逐段译文 + 生词高亮可点 + 1 道选择题 + 解析）
  - 听力 6 段（逐句 TTS、隐藏中文、三档语速）
  - 长难句 8 句（主干、成分拆解、读法提示）
  - **视频课 30 讲**：本地「考研英语核心母词 990」MP4，在素材 → 视频课里直接播放，支持上一讲 / 下一讲。
- **AI**：
  - 定制阅读：主题 + 难度 + 目标词（默认取最近"不认识/学习中"的词）→ 生成短文 + 逐句译文 + 生词高亮。
  - 串词成文：选 3–8 个陌生词 → 一段把它们串起来的小故事。
  - 默认**本地引擎**（离线、无需 Key）：用目标词的真题例句串成可读文本，英文段落保持纯英文，中文释义只出现在译文里。
  - 可在「我的 → 大模型」填入任意 OpenAI 兼容接口（baseURL / model / key），失败自动回退本地引擎。

## 九、已知边界

- **真题语料为教学改写**，标注了年份与题号，但不是逐字原文；词库中带剧集出处的例句为同类型风格示例，不是精确转录。
- **发音依赖浏览器语音合成**，音色随设备变化。
- **提醒为本地通知**：每日定时提醒在 App 安装后由本机触发，无需服务端；关闭 App 的通知权限后仅保留应用内提醒条。
- **数据在本机**：换设备需在「我的 → 导出备份」手动迁移。
- 词库目前 7786 词，来源为 OCR 与资料库 PDF；视频文件在本地，部署到线上不会自动包含。
- 本地 AI 生成依赖带例句的精讲词；当前词书没有例句，需接入大模型或补入精讲词。
